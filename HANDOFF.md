# HANDOFF — состояние проекта

_Обновлено: 11.11.2026_

## Структура

```
.
├── CLAUDE.md               правила проекта для Claude
├── HANDOFF.md              этот файл
├── .gitignore              исключает .env, ключи, токены, временные файлы, медиа, PDF
├── .env.example            шаблон переменных окружения (реальный .env не коммитится)
├── .claude/settings.json   подключение плагина roomwalk (Aironzak/instagram)
├── docs/
│   ├── research-summary.md выжимка исследования ниши
│   └── site-plan.md        структура сайта, порядок блоков, варианты реализации
└── site/                   статический сайт (без сборки)
    ├── index.html          разметка: первый экран, каталог, краны, «как купить», форма
    ├── css/style.css       стили, палитра А
    ├── js/models.js        каталог: 12 моделей из КП + 3 крана (цены, наличие, ТТХ, пути к фото и GLB)
    ├── js/app.js           3D-герой (three.js), карточки, книга ТТХ, форма
    ├── js/machines.js      свои 3D-модели из примитивов: 5 типов, гусеницы и колёса крутятся
    └── assets/img|models   фото из КП; сюда же кладутся GLB из Higgsfield
```

Первый экран: экскаватор JY625E едет слева направо по прокрутке, гусеницы крутятся в такт
(назад по скроллу — назад), мышью/пальцем вращается.
Свои 3D-модели (`js/machines.js`, бесплатно): типы crawler, wheeled, loader, dozer, backhoe;
тип и цвет задаются в `looks` в `js/models.js`. Это стилизация, а не точная копия машины.
Карточки: при наведении (на телефоне — по нажатию) фото сменяется своей 3D-моделью — один общий
WebGL-рендерер переезжает в карточку под курсором, OrbitControls, автоповорот, колёса едут.
Если у модели заполнен `glb` (настоящая модель из Higgsfield) — вместо своей показывается model-viewer.
Книга ТТХ раскрывается при наведении, на телефоне — по нажатию.

## Как запустить

1. `git clone https://github.com/aleksarulezzz-lab/spectechnika && cd spectechnika`
2. `cp .env.example .env` и заполнить при необходимости.
3. Открыть в Claude Code: плагин roomwalk предложится к установке из
   `.claude/settings.json` (или вручную: `claude plugin marketplace add Aironzak/instagram`,
   `claude plugin install roomwalk@roomwalk`).
4. Higgsfield: на своём компьютере выполнить `/roomwalk:connect` (откроет вход в браузере,
   нужен аккаунт с кредитами), перезапустить Claude Code, затем `/roomwalk:start`.
   В облачных сессиях Higgsfield уже подключён как свой коннектор claude.ai
   (`https://mcp.higgsfield.ai/mcp`, настройки по умолчанию) — ничего делать не нужно.
5. Сайт: `cd site && python3 -m http.server 8000`, открыть http://localhost:8000
   (нужен интернет: three.js и model-viewer грузятся с cdn.jsdelivr.net).
6. Добавить 3D-модель: положить `site/assets/models/<id>.glb` и прописать `glb` в `js/models.js`;
   для героя при необходимости подобрать `heroYaw` (поворот, чтобы машина смотрела вправо).

## Принятые решения

- Основа всех решений — исследование ниши (ноябрь 2026). Порядок блоков = сила страха
  покупателя: запчасти → оплата → цена/наличие → бренд → гарантия → статус.
- Цель каждой страницы — заявка или мессенджер; «Цена по запросу» запрещена.
- Палитра А (бирюза + оранжевый CTA), шрифты Manrope/Onest + Inter/Golos Text.
- PDF исследования и КП не храним в git (лежат в файлах проекта).
- Плагин roomwalk проверен 11.11.2026 (коммит 88e1773): делает героя-видео, которое
  листается скроллом; генерация через Higgsfield (платно, 25–80 кредитов за черновик).
  Скрипт входа `connect_higgsfield.py` сам проводит OAuth и пропускает проверку `iss`
  (обходит ошибку Higgsfield), токен пишет в `~/.roomwalk/` и в пользовательский
  MCP-конфиг. Версия в settings.json не закреплена — при обновлении смотреть изменения.

## Как запустить

1. `git clone https://github.com/aleksarulezzz-lab/spectechnika && cd spectechnika`
2. `cp .env.example .env` и заполнить при необходимости.
3. Открыть в Claude Code: плагин roomwalk предложится к установке из
   `.claude/settings.json` (или вручную: `claude plugin marketplace add Aironzak/instagram`,
   `claude plugin install roomwalk@roomwalk`).
4. Higgsfield: на своём компьютере выполнить `/roomwalk:connect` (откроет вход в браузере,
   нужен аккаунт с кредитами), перезапустить Claude Code, затем `/roomwalk:start`.
   В облачных сессиях Higgsfield уже подключён как свой коннектор claude.ai
   (`https://mcp.higgsfield.ai/mcp`, настройки по умолчанию) — ничего делать не нужно.
5. Команда запуска сайта появится после выбора стека (см. `docs/site-plan.md`).

## Принятые решения

- Основа всех решений — исследование ниши (ноябрь 2026). Порядок блоков = сила страха
  покупателя: запчасти → оплата → цена/наличие → бренд → гарантия → статус.
- Цель каждой страницы — заявка или мессенджер; «Цена по запросу» запрещена.
- Палитра А (бирюза + оранжевый CTA), шрифты Manrope/Onest + Inter/Golos Text.
- PDF исследования и КП не храним в git (лежат в файлах проекта).
- Плагин roomwalk проверен 11.11.2026 (коммит 88e1773): делает героя-видео, которое
  листается скроллом; генерация через Higgsfield (платно, 25–80 кредитов за черновик).
  Скрипт входа `connect_higgsfield.py` сам проводит OAuth и пропускает проверку `iss`
  (обходит ошибку Higgsfield), токен пишет в `~/.roomwalk/` и в пользовательский
  MCP-конфиг. Версия в settings.json не закреплена — при обновлении смотреть изменения.
